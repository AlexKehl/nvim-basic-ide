# Neovim Configuration - Claude Context

Personal Neovim configuration, written in Lua. It was briefly migrated toward
Fennel; that was reverted in October 2026 and everything is plain Lua now.

## Architecture

```
.
├── init.lua                    # Entry point: requires all user modules + VimScript block
├── docs/                       # Design notes for non-obvious setups
└── lua/user/
    ├── plugins.lua             # lazy.nvim plugin specs
    ├── options.lua             # Vim options
    ├── keymaps.lua             # Key mappings (leader = space)
    ├── autocommands.lua        # Autocommands
    ├── colorscheme.lua
    ├── blink.lua               # Blink completion config
    ├── blink-clojure-keywords.lua   # Custom blink source: :ns/keyword from buffers
    ├── blink-conjure-map-keys.lua   # Custom blink source: keys of last Conjure result
    ├── cmp.lua                 # nvim-cmp config
    ├── conjure.lua             # Clojure REPL integration
    ├── dadbod.lua              # Database integration
    ├── debugprint.lua
    ├── formatter.lua           # formatter.nvim per-filetype config
    ├── gitsigns.lua
    ├── lilypond.lua
    ├── lualine.lua
    ├── oil.lua                 # File explorer
    ├── telescope.lua
    ├── treesitter.lua
    ├── comment.lua
    ├── expandregion.lua
    ├── sneak.lua
    ├── luasnip/                # Snippet engine config + snippets/<lang>.lua
    └── lsp/
        ├── init.lua            # Entry: mason + handlers.setup()
        ├── handlers.lua        # on_attach, keymaps, custom commands, vim.lsp.config/enable
        ├── mason.lua
        └── settings/           # Per-server settings tables
```

Several files were generated by compiling Fennel through nfnl and still carry
that style (`_1_` closure names, `return` on the last statement). Clean them up
opportunistically when touching them; do not restore Fennel.

## Key Technologies

- **lazy.nvim** plugin manager (`lua/user/plugins.lua`, versions in `lazy-lock.json`)
- **LSP** via `vim.lsp.config` / `vim.lsp.enable` in `lua/user/lsp/handlers.lua`, servers installed by Mason
- **Treesitter**, **Telescope**, **Blink** / **nvim-cmp**, **LuaSnip**, **Gitsigns**, **Oil**, **Lualine**
- **Conjure** + **vim-sexp** for Clojure (and other Lisps)
- Languages: Clojure, TypeScript/JavaScript, Lua, Gleam, LilyPond, SQL (vim-dadbod)

## Development Guidelines

- Edit the Lua files directly. One feature per file under `lua/user/`.
- New module: create `lua/user/<name>.lua`, add `require("user.<name>")` to `init.lua`.
- Format with `stylua` (tabs, matching the existing files).
- Test by running `nvim --headless "+lua require('user.<name>')" +qa` or restarting Neovim.

## Common Tasks

- **Install a plugin**: add a lazy.nvim spec in `lua/user/plugins.lua`, then `:Lazy sync`.
- **Add an LSP server**: `:MasonInstall <server>`, then `vim.lsp.enable`/`vim.lsp.config` in `lua/user/lsp/handlers.lua`; per-server settings go in `lua/user/lsp/settings/`.
- **Keymaps**: `lua/user/keymaps.lua`. Buffer-local LSP keymaps live in `lsp_keymaps` in `handlers.lua`.
- **Autocommands**: `lua/user/autocommands.lua`.
- **Snippets**: `lua/user/luasnip/snippets/<filetype>.lua`.

## Special Configurations

- **VimScript block in `init.lua`**: visual search/replace helpers, keepjumps for `{`/`}`,
  filetype marks (`<leader>gj` JS/TS, `<leader>gc` Clojure, ...), terminal escape
  `<leader><Esc>`, Copilot and mergetool settings, vim-sexp mapping overrides.
- **Clojure Java interop** (`gd` on Java members, `.method` completion via Conjure/cider-nrepl):
  see [docs/clojure-java-interop.md](docs/clojure-java-interop.md); planned follow-ups in
  [docs/clojure-java-interop-next.md](docs/clojure-java-interop-next.md).
- **java_language_server** only starts when a Gradle/Maven root exists (see bottom of `handlers.lua`).
